📌 How Approvals Work
  • Late arrival / extended lunch with NO manager approval → deduction IS applied automatically
  • Manager APPROVES (with comment) → deduction is WAIVED, full 45 min kept
  • Manager REJECTS (with comment) → deduction IS applied
  • On-time arrival (≤07:45) always gets full 45 min — no approval needed
  • Sick leave → 0 accumulation
